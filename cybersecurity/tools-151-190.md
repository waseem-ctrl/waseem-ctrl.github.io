# Tools 151-190, public white-hat sources

Added 1 Oct 2026. Continues the index. Sources: r/netsec (Tracebit canaries, Open Security Architecture patterns), r/osinttools DEF CON 34 investigation hygiene, Bellingcat toolkit categories, OWASP projects, abuse.ch, and X posts that name Wazuh, VirusTotal, and OpenCTI.

Same rule: written scope, client-owned systems. No install steps and no attack procedures.

## Threat intel and malware lab

151. VirusTotal. Hash and URL lookup for a sample the client handed you.
152. MalwareBazaar. Known-malware hash check for that sample.
153. ThreatFox. Indicator lookup tied to the incident.
154. Feodo Tracker. Botnet C2 check against client logs.
155. AlienVault OTX. Pulse lookup for indicators already in the case.
156. Malpedia. Family reference while writing the report.
157. REMnux. Lab distro for the sample, not a production host.
158. CAPE sandbox. Detonate the sample in an isolated lab.
159. urlscan.io. Lookup of a URL from the client's mail or logs.
160. GreyNoise. Decide if a scanner IP in their logs is background noise.

## Supply chain and application security

161. OWASP Dependency-Track. Track vulnerable libraries in a bill of materials they provided.
162. OWASP Threat Dragon. Threat model of a system they described.
163. osv-scanner. Match that bill of materials to the OSV database.
164. SonarQube. Static review of a repository in scope.
165. Bandit. Python static checks on that repository.
166. Opengrep. Community rulesets for a repository in scope.
167. Sigstore / cosign. Verify signatures on images they deploy.
168. HashiCorp Vault. Secrets storage for an engagement, client-held.
169. SOPS. Encrypt secrets in a repo they own.
170. OWASP CRS with Coraza or ModSecurity. WAF rules on an app they own.

## Detection engineering and canaries

171. MITRE ATT&CK Navigator. Map findings to techniques in the report.
172. Atomic Red Team. Lab tests of detections on a range they own.
173. Caldera. Adversary emulation in that lab.
174. Canarytokens. Tripwires on assets the client placed them on.
175. OpenCanary. Same, self-hosted.
176. Tracebit Community Edition. Canaries for SSH, cloud keys, and mail, client account.
177. Falco. Runtime alerts on a cluster they own.
178. Tracee. Runtime tracing in that cluster or lab.
179. Snort. IDS rules on a span they provided.
180. Malcolm. Network capture and Zeek analysis appliance for an incident.

## Investigation hygiene and archiving

181. Obsidian. Case notes and source log for the engagement.
182. ArchiveBox. Save pages cited in the report.
183. Wayback Machine. Check what a client page looked like on a date.
184. crt.sh. Certificate history for a domain they own.
185. SecurityTrails. Passive DNS for that domain.
186. BGPView. ASN and prefix context during an incident.
187. InVID / WeVerify. Verify a photo or video the client asked about.
188. KeePassXC. Local vault for engagement secrets.
189. Open Policy Agent. Policy checks on IaC they provided.
190. Open Security Architecture patterns. Gap assessment against published control maps, not a scanner.

Not added: people-search and face-search sites, paid breach aggregators, the ESP32 Bleach firmware, all-in-one hacking packs.
